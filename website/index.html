核心功能

AI 不是独立功能——它整合在每一次操作里

▦

项目看板

按健康状态分列（活跃 / 待处理 / 停滞 / 其他），卡片带脉搏徽标和快捷动作。状态由引擎从 git 事实推导，不可手改。

🚩

里程碑管理

绑定 git tag 自动判定达成。行内直达按钮：达成 / 重开 / 放弃 / 删除。点击行跳到项目详情。

✦

AI 整合更新流

浅更新 + AI 摘要 / 深度更新 + AI 报告 / 定时更新 + AI 简报通知。AI 不在独立页面——它在每次操作里。

⚡

一键项目说明

项目页一键生成说明：结合 README、代码构成、进度事实，面向第一次接触的人。500 字以内。

🌿

Git 白名单操作

pull / push / commit / stash / unstash / fetch。结果输出区实时反馈。没有 reset / clean / force-push。

📄

文档平铺

README / AGENTS / CLAUDE 原文在项目详情页平铺渲染。引擎保证只改托管区域，其余逐字节保留。
